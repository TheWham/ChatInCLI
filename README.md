# ChatInCLI

微信 PC 版（4.x）命令行聊天工具 —— 在终端里跟多个好友收发消息，全程不操作微信窗口（微信最小化到后台），适合「摸鱼」。

基于 [pywechat](https://github.com/Hello-Mr-Crab/pywechat)（纯 UI 自动化，无 Hook 注入）。

## 特性

- **完全后台收发**：发消息、切换会话都不弹微信 UI，窗口始终保持最小化
- **多会话快速切换**：`/list` 列最近会话，`/名字` 一键切换
- **新消息提醒**：跟 A 聊天时，能识别「B 发来 N 条新消息」并提示
- **防串聊**：收发前校验当前聊天对象，被新消息切走时自动切回
- **消息类型提示**：文本完整显示，文件/图片/链接显示 `[文件] xxx` 提示

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| 操作系统 | Windows 10 / 11（64 位） |
| Python | ≥ 3.10 |
| 微信 | 4.x（已登录、UI 树可见） |

> 微信需保持登录运行（窗口可最小化但勿退出）。账号需「UI 树可见」（老号通常可见，新号可能不行）。

## 安装

```bash
pip install pywechat127
```

## 使用

```bash
python chat_cli.py
```

启动后列出最近会话，用 `/名字` 选一个进入对话，之后：

| 命令 | 作用 |
| --- | --- |
| 直接输入文字 | 发送给当前好友 |
| `/list` | 列出最近 20 个会话 |
| `/名字` | 切换到该好友（如 `/肖维`、`/T`） |
| `/quit` | 退出 |

对方来消息约 2 秒内打印；其他好友发来新消息时会提示：

```
[16:20] 【肖维 发来 3 条新消息，输入 /肖维 切换】
```

## 实现要点（微信 4.x 适配）

- **发送**：`set_text()` 写入 + `PostMessage` 给主窗口发鼠标点击消息（按缓存坐标点「发送」按钮）。微信 4.x 的 Qt 发送按钮不支持 UIA `invoke()`，但 `PostMessage` 的 `WM_LBUTTONDOWN/UP` 有效，且最小化状态下可用。
- **切换**：会话项在最小化状态下 `rectangle()` 返回乱码坐标，故**在窗口恢复时缓存坐标**，之后用缓存坐标 PostMessage 点击，实现无感切换。
- **识别谁发来消息**：读左侧会话列表的 `[N条]` 未读红标（纯 UIA，最小化可读）。
- **防串聊**：读 `CurrentChatNameText` 校验当前聊天对象（注意库会给它塞残留 `title` 字段，需剔除）。

## 已知限制

- 仅支持单聊场景下正确判断发送者（群聊会把所有人显示成群名）
- 若你在**手机**（同一微信号）上发消息，该消息会被误显示成对方（微信 4.x 后台读不到聊天消息的发件人）
- 坐标只有在窗口恢复状态才能读到：若启动时微信是最小化的，首次切换/发送会短暂闪一下以缓存坐标，之后全程无感
- 需要 UI 树可见的账号，且不要手动拖拽改变微信窗口大小
