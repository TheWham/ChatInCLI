# ChatInCLI

微信 PC 版（4.x）命令行聊天工具 —— 在终端里选一个最近会话、跟对方收发消息，全程不操作微信窗口（微信最小化到后台），适合「摸鱼」。

基于 [pywechat](https://github.com/Hello-Mr-Crab/pywechat)（纯 UI 自动化，无 Hook 注入）。

## 特性

- **完全后台收发**：发消息不弹微信 UI，微信窗口保持最小化
- **防串聊**：收发前校验当前聊天对象，被新消息切走时自动切回
- **消息类型提示**：文本完整显示，文件/图片/链接显示 `[文件] xxx` 提示

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| 操作系统 | Windows 10 / 11（64 位） |
| Python | ≥ 3.10 |
| 微信 | 4.x（已登录、UI 树可见） |

> 微信需保持登录运行（窗口可最小化但勿退出）。账号需「UI 树可见」（老号通常可见，新号可能不行）。

## 安装

```bash
pip install pywechat127
```

## 使用

```bash
python chat_cli.py
```

1. 运行后列出最近 50 个会话，输入编号选择
2. 进入对话后微信自动最小化，终端出现 `我 >` 提示符
3. 输入消息回车发送，对方消息约 2 秒内打印
4. 输入 `/quit` 退出并恢复微信窗口

## 已知限制

- 仅支持单聊场景下正确判断发送者（群聊会把所有人显示成群名）
- 若你在**手机**（同一微信号）上发消息，该消息会被误显示成对方（微信 4.x 后台读不到发件人）
- 需要 UI 树可见的账号，且不要手动拖拽改变微信窗口大小
